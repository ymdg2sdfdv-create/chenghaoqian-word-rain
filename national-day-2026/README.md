# 国庆六天早读（2026）

入口 `index.html`。这是独立的静态课程载荷，维护源在同级“陈浩谦高考英语提升系统”。不手改 data.js，不覆盖 Unit1 / Week2 / wordrain_v3 学习记录。

- 629条课堂记录 → 488个复习单元 → 593张按课堂词形、词性、义项区分的词卡。每天分别248、300、213、248、216、297张，已包含计划复习。
- 第1—3天：每词2轮拆分拼写，删除中文提示回忆，4次单词爆炸。每轮拆分后完整英文＋中文揭示；因此完整英文6遍、中文2遍，另有2轮逐字母／词块拼读。
- 全部早读后，显示英文和课堂词性；认识直接下一词，不认识显示答案并发音，整轮结束后只把不认识词按首轮滚动一遍。无不认识词时直接完成。
- 第4—6天：保留同组关系，组内调整顺序；根据原课堂句子挖空或课堂词义与词性主动回忆，口述或输入答案，揭晓后核对词族、近义与反义辨析，再自评独立答出或还需复习。全部回忆后补读不认识词。第1—5天的不认识词并入次日队列，去重后优先呈现；每一天开始后队列固定，刷新不会突然改变范围。
- 学习单元按分类小组编排，跨课重点优先；一个词族中的不同形式分别自评。选择认识是自评，补读完成不等于掌握。
- 学习记录独立保存在 `wordrain_national_day_2026_v1`。暂停、切后台、刷新或关闭后，从当前未完成词继续；不会跨自然日清零。导出按钮可保存原始记录。不同浏览器与不同域名的记录互不共享。
- iPad 11寸：横竖屏自适应，834×1194、834×1210及反向尺寸；安全区、动态视口、44px以上触控区域、大字词卡、长词组换行、减弱动态效果支持。Safari首次播放需要一次点击。
- 1200份本地MP3：完整英文、按课堂义项区分的中文、拆分词块／字母。audio-manifest.json 记录文本、时长和校验值；语音失败时明确提示并保留当前位置。

源端生成器：`scripts/build_national_day_2026.py`、`scripts/build_national_day_audio.py`。
源端检查：`node tests/national-day/core.cjs`、`node tests/national-day/browser.cjs`（WebKit: `ND_BROWSER=webkit`）。
完整目录可离线本地托管；GitHub网站首次使用与未缓存语音需要联网。本模块不声称所有网页资源已经由Safari自动离线缓存。
