# 1200词早读系统进度存储 v3 设计

## 背景

陈浩谦当前电脑仍保存899词时代的浏览器进度。删除仓库中的899词库文件不会清除浏览器 `localStorage`；现有 `wordrain_v2` 又是在1200词升级前已经启用，因此继续读取它可能带入旧课程日、旧词条记录和旧复习节点。

## 目标

为1200词体系建立全新的进度命名空间，使899词旧进度无法干扰当前课程，同时保持现有学习流程和严格复习规则不变。

## 方案

1. 将当前进度键从 `wordrain_v2` 升级为 `wordrain_v3`。
2. v3 不读取、不迁移 `wordrain_v2`、`wordrain_sr` 或 `wordrain_day`。
3. 899词旧数据保留在浏览器中但完全隔离，不主动删除，便于必要时追溯。
4. 首次打开1200词系统时创建全新进度，从 Day 01 开始。
5. v3 数据同时保存：
   - `version: 3`：存储结构版本；
   - `bankVersion: "1200-v2.0-2026-08-03"`：词库版本；
   - `courseDay`、`lastAdvancedDate`、`entries`、`dayCompletion`：沿用现有业务字段。
6. 学习条目继续使用稳定课程ID保存。词义或大小写调整不影响已经形成的v3进度。

## 加载与异常处理

- 没有 `wordrain_v3` 时，直接创建空白v3进度。
- 读取时必须同时验证 `version`、`bankVersion`、课程日、词条集合和完成记录的基本结构。
- 只接受当前 `ITEM_BY_ID` 中存在的词条ID；未知ID会被清理，避免未来残留数据污染统计。
- v3 JSON 损坏或版本不匹配时，将原始内容备份到带时间戳的隔离键，再创建空白进度。
- 保存仍使用本机 `localStorage`，本次不增加账号、云同步或跨设备合并。

## 重置行为

“重置进度”只清除 `wordrain_v3` 并重新创建空白v3进度。旧版键不参与运行，也不因重置被删除。

## 不变范围

- 不修改1200词内容、30天分配和日内顺序；
- 不修改 `+1、+2、+4、+7、+15天` 复习节点；
- 不修改播放、拼读、长短语显示、语音和页面视觉；
- 不迁移899词学习成果；
- 不实现进度导出/导入和云同步。

## 验收测试

1. 浏览器仅存在旧 `wordrain_v2` 时，系统从 Day 01 创建独立的 `wordrain_v3`。
2. 学完词条、完成课程日和完成复习后，刷新页面仍能正确恢复v3进度。
3. 旧版键中的课程日、旧词条和复习记录不会进入页面统计或任务队列。
4. v3 中注入未知词条ID后，加载时会清理该记录且不影响有效记录。
5. v3 损坏或 `bankVersion` 不匹配时，旧内容被隔离备份，页面以空白进度正常启动。
6. 重置后 v3 从 Day 01 开始，旧版键仍保留但不被读取。
7. 静音设置 `wordrain_muted` 继续正常工作。
