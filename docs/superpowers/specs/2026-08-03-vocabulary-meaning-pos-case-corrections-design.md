# 1200 高频词词义、词性与大小写修订设计

## 目标

在不更换词条、不改变 30 天分配及日内顺序的前提下，全面审核并修正 1200 个词条的英文大小写、中文核心词义和词性，使其符合高考英语教学与早读使用习惯，并能准确定位到“第几天第几个词”。

## 修订原则

1. 以高考最常见用法为主，通常每个词条保留一个核心词性和核心义项。
2. 只有两个义项都具有较高考试价值且属于同一词性时，才用分号补充第二义项。
3. 不迁就现有错误中文：词性错误时直接修正词性，释义错误时直接修正释义。
4. 专有名称、国籍和地区派生词按规范调整首字母大小写。
5. 短语保持现有英文形式和位置，仅在确有词义、词性或大小写错误时修订。
6. 不改变总词数、每天词数、词条编号、日序和词条类型分配。

## 数据范围与同步

唯一词源及所有用户可见副本必须保持一致：

- Markdown 词库源文件；
- Excel 人工修订版中的核心总表、30 天学习安排及相关索引；
- 网页使用的 `word-bank-data.js`；
- 与修订后中文释义对应的中文音频文件。

英文只发生大小写规范化时沿用原发音；如文件名受大小写影响，则同步调整资源名称和引用。旧版 899 词独立页面不纳入本次 1200 词修订。

## 处理流程

1. 解析 1200 词，建立“天数、日内序号、英文、中文、词性、类型”的统一审核表。
2. 先用规则筛查明显问题，包括词性与中文不匹配、把名词义写成动词义、形容词漏“的”、使役动词漏“使”、错误大小写和注释残留。
3. 对多义词逐条做教学语境复核，按高考常见度选定核心义项。
4. 将确认后的修订一次性同步到各数据文件，保持所有编号和排序不变。
5. 对受影响的中文语音进行定向更新，不全量重建无关音频。
6. 执行结构校验、跨文件一致性校验、页面抽查和音频资源校验。

## 验收标准

- 仍为 30 天、每天 40 项、总计 1200 项；
- 英文词条顺序和编号不变；
- Excel、Markdown 与网页词库逐项一致；
- 所有调整后的词义与词性互相匹配；
- 国籍及专名大小写符合英语规范；
- 受影响的中文音频与新释义一致且可解码；
- 输出完整修订清单，至少包含：天数、日内序号、原英文、修订后英文、原词性/词义、修订后词性/词义、修订原因。

## 风险控制

- 对 `lie`、`conduct`、`degree`、`character` 等多义词按所在语义组和高考常见用法共同判断，避免机械替换。
- 不触碰工作区内与本任务无关的既有删除或修改。
- 音频仅定向更新发生中文变化的词条，降低耗时并避免无关资源波动。
